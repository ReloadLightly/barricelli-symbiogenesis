# Mission: barricelli-symbiogenesis

Develop a working ALife laboratory and artistic instrument with three equal purposes:
1. Explore how simple numerical interactions produce complex organization.
2. Test what modern LLM-assisted discovery adds using fair, logged comparisons.
3. Create beautiful, reproducible visual works from saved numerical dynamics.

Preserve useful existing work and inspect uncommitted changes before editing. Use CPU-friendly, resumable batches; stream numeric output. This WSL machine has 8 logical CPUs but only about 3.7 GiB RAM and little available memory: execute experiments serially and avoid retaining animation frames in memory.

Keep `barricelli1954_reference`, `galloway_published`, and explicitly named research variants distinct. Preserve Taylor's GPLv3 attribution and notices. Galloway's retrieved sketch has no explicit software license; independently implement its behavior, retain source hashes, and compile a temporary source-level oracle from a privately retrieved file rather than bundling the program.

Every displayed form must derive from a saved numerical trajectory. Design rules, initial conditions and presentation; let dynamics generate the forms. Do not use hidden target pictures or scripted organism motion. Label external interventions. Identify the time axis in 1D space-time works.

Save exact integer starting rows, seeds, configurations, source/binary hashes, timing, render recipes and complete run registers. Maintain `RESEARCH_RECORD.md` and per-experiment manifests. Keep aesthetic curation separate from aggregate evidence and keep failed or unpromising outcomes.

Compare random search, non-LLM novelty/archive search and feedback-informed conversational Codex proposals in the same admissible space and simulator budget across repeated searches. Log proposal times, inputs, feedback, actual model usage and execution. Do not describe conversational assistance as an automated integration. No paid services or per-cell model dependency; new paid access requires user authorization.

Measure recurrence, persistence and interpretable structure with periodic/noisy controls. Treat seeds/worlds as experimental units. Equal values and visual novelty do not imply ancestry, life, symbiosis, intelligence or open-ended evolution. Causal assays require organization/partner perturbations, matched damage, shuffling and rescue, and separate translation/domain spread from detached viable reproduction.

Run constituent-rule controls for heterogeneous environments with matched initial states, total cells and update budgets. Reserve unseen states and longer horizons for confirmation. Negative results are valid outcomes. Cite verified primary sources and distinguish read versions from inaccessible papers.

The milestone requires verified reference simulations, an offline replayable atlas, curated prints and reveal animations, an executed search comparison, a matched heterogeneity experiment, a causal case study, and an illustrated paper-style README with findings, limits, commands and the next experiment. Hosting and external publication are outside this repository milestone.

The user explicitly authorized GitHub checkpoint pushes and an informative repository About. Commit and push each completed design, implementation, execution and verification stage to the configured `origin`, preserving earlier work and outcomes. Keep the repository description and relevant topics informative. Preserve earlier per-run provenance and timing/resource measurements when regeneration refreshes them; compressed metadata histories must not be counted as additional experimental units. Live hosting remains outside the authorized repository work.

Before each round, record its question, measures, resource budget and completion criteria. Complete rounds with evidence and deliverables even when results are negative. Keep the three mission goals equal and stable while adapting hypotheses. Do not let further calibration indefinitely postpone discovery and numerical art. Broader comparisons must provide comparable own-history information and logged saved visual results as well as numerical feedback for conversational Codex.
